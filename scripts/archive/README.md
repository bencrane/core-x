# scripts/archive

Retired one-off investigation scripts — probes, diagnostics, recons, and sizing
simulations that answered a specific question at a point in time (structural probes of
Lance datasets, coverage/overlap recons, extraction-backlog sizing, plan-phase
diagnostics). They are kept for reference because docs under `docs/plans/` and
`docs/reference/` cite their methodology and output; they are not part of any live
pipeline, Modal app, or scheduled job, and nothing imports them. Do not build on them —
write a new script (or promote logic into `pipelines/`) instead.
